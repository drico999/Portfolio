## Deploy to GitHub Pages

1. Push this repo to GitHub (repo name: `drico999.github.io` for root URL)
2. Go to **Settings → Pages → Deploy from branch**
3. Select `main` branch, `/ (root)` folder → Save
4. Site goes live at `https://drico999.github.io`
